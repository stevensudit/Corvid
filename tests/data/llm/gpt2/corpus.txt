== Prose, to make up the token count for the gradient batch ==
Corvid is a header-only C++23 library with minimal external
dependencies. All headers live under corvid/. The build compiles the
test suite as C++26 where the toolchain allows, but the code stays
C++23: C++26 features are permitted only inside headers gated on their
feature-test macro, such as the reflection layer under meta/invoke/.
When a function can fail, prefer returning a status over void. Token
is reserved for things that are literally named tokens; do not use the
word loosely to mean handle, callback, view, ticket, or marker.
This is a C++ library, so we minimize how much raw C surfaces in
calling code: wrap C dependencies in C++-native idioms rather than
exposing them directly. RAII for every C resource, a variant over a
tagged union, a typed status over a bare error code. Keep the C behind
the wrapper; do not let it leak out.

Byte-level BPE can encode any byte sequence, including bytes that are
not valid UTF-8. This file is valid UTF-8 throughout; invalid input is
a separate unit test, since a text fixture cannot carry it.
